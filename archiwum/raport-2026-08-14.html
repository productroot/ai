UPDATE · Claude Code

Auto mode default — co się zmienia, a co nie

UPDATE Blog z 7.08: od 14 sierpnia nowe sesje Pro/Max/Team lecą w auto, chyba że użytkownik ma przypięty własny default — wtedy jednorazowe pytanie, czy przełączyć. Przypięty default bez zgody = bez zmian.

Bez zmian dziś: Enterprise, API, Claude Platform on AWS, Bedrock, Google Agent Platform i Microsoft Foundry zostają przy opt-in. Admini Enterprise mogą wymusić default przez managed settings. Anthropic zapowiada default „w nadchodzącym miesiącu” — to plan, nie fakt dnia.

Auto mode nie pyta przy każdej komendzie: klasyfikator blokuje akcje nieodwracalne, destrukcyjne albo skierowane poza środowisko. Po 3 blokadach z rzędu albo 20 w sesji — powrót do ręcznych zgód. Shift+Tab przełącza tryb.

Docs (permission-modes): „Starting August 14, 2026, auto mode becomes the default permission mode for new sessions on Pro, Max, and Team plans.” Brak komunikatu o delay albo rollback.

Fakt: harmonogram i dokumentacja. Spekulacja: skala problemów u użytkowników — za wcześnie rano CEST.
